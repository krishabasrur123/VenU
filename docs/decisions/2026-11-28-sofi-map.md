# SoFi map 2026-11-28: decisions

Branch `jayden/sofi-map`, stacked on `jayden/venue-demo` (PR #13). Goal: bring SoFi's map up to
Intuit Dome's, and add an Outside / Inside layer toggle. Made overnight without Jayden; each line is
a decision, then why.

## Sources
- A-Z guide, accessibility, stadium policies, parking and transportation, accessible parking and
  rideshare pages on sofistadium.com (read 2026-11-28; URLs in the `SOFI` comment in `mock.ts`).
- Maps: the parking zones map (outside layer, as before) and SoFi's own Level 3 and Level 6
  concourse maps (Cartifact, 09.20.24), hotlinked from `www.sofistadium.com/assets/img/`:
  - `Level-3-SoFi-Stadium-F-82c625ccc3.jpg` (2550×3300)
  - `Level-6-SoFi-Stadium-F-1331ea6520.jpg` (2550×3300)
  No current page links them (`/plan-your-visit/seating-map` now redirects to the interactive
  map); they turned up in the Wayback Machine's index of `sofistadium.com/assets/img/`, and both
  still load with a foreign referer (no hotlink block). If SoFi deletes them, the layer shows the
  existing "Couldn't load the map" cover with Try again; the facilities still list and search.
- The interactive Mappedin map (`/plan-your-visit/maps`) wasn't used for pins: it's a 3D web app
  with no static image, and reading its data would mean calling Mappedin's API with the key embedded
  in SoFi's page. So no "Open in SoFi's map" deep link per facility either (optional item, skipped:
  coordinates and floor ids couldn't be confirmed without that data).

## Layers
- Generic: `VenueMap.layers` (id, kind outside/level, image, focus, widthMeters, `toBase`), and
  `Facility.layer` (unset = the first layer). Only SoFi has layers; Intuit Dome and Crypto.com Arena
  are untouched (one implicit layer, no toggle; Crypto's bundled `local:` blueprint still resolves).
- Three SoFi layers, not two: Outside, Level 3 and Level 6. Level 3 has both sensory rooms, four
  Guest Services desks and the ramp; Level 6 (the Main Concourse, all 300 sections) has the two
  first aid rooms the guide lists there, the adult changing station and hydration stations. Level 4
  (suites) was left out: it has no first aid room or sensory room, and a fourth toggle option
  crowds the map on a phone.
- The toggle is a segmented pill ("Outside · Level 3 · Level 6") under the source bar, a radio group
  for screen readers. The list and search show every facility; opening one on another layer
  switches the map to it (the layer follows the open facility; the toggle overrides until the next).
- `toBase` is a normalized affine placement of a level map on the parking map, fitted from four
  entries (Level 3's VIP Entry 6, 7, 11, 12 elevators on those entries) plus the bowl centres:
  scale 0.2996, rotation −31° (the Cartifact maps draw the field vertical with "north" up; the
  parking map has true north up). Overlaid, the Level 3 map's roof, field and entries line up within
  about 50 px. Both level maps share one frame (the field sits on the same pixels).

## Walks across layers (the rule)
- A walk is measured and drawn on the facility's layer, from where the start falls on that layer
  (e.g. Entry 4 lands just outside the north-west of the Level 3 ring), plus 2 minutes
  (`LEVEL_CHANGE_MINUTES`) when the layers differ. The list, pin card and route panel use the same
  number (`walkFrom`).
- Steps add "Take an elevator or escalator to Level 3." after the start, or "Head for the nearest
  exit and go outside." when the facility is outside and the start inside. Not "up" or "down": the
  site doesn't say which level the gates open onto.
- Headings follow the map on screen (the level map's own "north"), so "Head southeast" matches the
  line the visitor sees.
- Considered and dropped: routing through the nearest entry as a waypoint (GA entries aren't drawn on
  the level maps, so the inside half would start from a guess).
